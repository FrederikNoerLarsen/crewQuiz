Spotify‑opsætning

Afspilning i browseren kræver Spotify Premium og et gratis udvikler‑app‑ID.

  1. Gå til developer.spotify.com/dashboard og log ind.
  2. Klik Create app. Navn/beskrivelse er lige meget.
  3. Sæt Redirect URI til præcis: — klik Add.
  4. Under Which API/SDKs are you planning to use: sæt flueben ved Web API og Web Playback SDK.
  5. Gem, åbn appen, og kopiér Client ID ind herunder.

Uden Spotify virker quizzen stadig — “Hint” viser så bare sangtitel og starttidspunkt, så du kan afspille manuelt.
