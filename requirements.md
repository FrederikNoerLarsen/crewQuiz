Mission:
Jeopardy like game with different categories displayed in columns with the lowest value at the top and the highest value at the buttom. 

Behaviour:
When pressing a value within a category the question is shown. Here needs to be 2 buttons: "Hint" and "Show Answer". For questions where a song will be played the "Hint" button will play the song. When the answer is shown a back button needs to be availalbe for going back to the first view. Clicking the hint button again stops the song.

Features:
The app should be connected to spotify and be able play songs at a certain time.
